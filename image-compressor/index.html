What does this image compressor do?

This tool re-encodes an image in your browser to create a smaller file. It is useful when an image is too large for a website, upload form, email or messaging service.

Supported formats

  • JPG / JPEG for photographs and general-purpose images.
  • WebP for modern websites and smaller web assets.
  • PNG when you need lossless output or transparency.

Is my image uploaded?

No. The compression process runs locally in your browser using the Canvas API. The selected image is not sent to a Toolkit server by this page.

Compression results vary by image dimensions, format and quality setting. Converting a PNG to JPG or WebP can change transparency and image characteristics.
